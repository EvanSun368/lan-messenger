# Repository source contents

This GitHub branch adds `telegram-lan-prototype/` alongside the existing project.
It includes application source/tests, source-scope/license records, original emoji
engine/generator inputs and the pinned full-lib_ui build host. Upstream checkouts,
SDKs, dependency archives, build outputs, private TLS fixture keys and source ZIPs
are excluded. Generate a disposable test fixture before running transport tests.

The current entry point is [README.md](README.md), with exact feature and platform
limits in [application/README.md](application/README.md). See the final integration
validation record rather than older build counts when reviewing this revision.
There is no new executable release or Windows acceptance claim.
