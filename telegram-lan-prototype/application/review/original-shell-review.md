# 原版 Telegram 控件集成审查

本阶段不是将 Telegram 换成局域网协议后完整运行。实际链接固定版本的
原版 lib_ui，复用其标题栏、编辑器、搜索框、图标按钮、弹出菜单、滚动区和
消息文本组件；局域网会话、历史、传输模型仍由 LanLink 提供。

## 已处理的实际问题

1. 原版 IconButton 不提供宿主 Qt 布局所需的最小尺寸，附件/发送/搜索曾被
   压成零宽。按原版样式尺寸固定，宽窗和窄窗测试检查可见、非零、无重叠。
2. 原版 PopupMenu 接管 QMenu 所有权，直接传持久命令模型会在关闭后留下
   悬空指针。每次创建独立递归命令副本，QPointer 安全转发业务动作。
   导航、会话和附件菜单都重复开关验证，保留发送快捷键子菜单和勾选状态。
3. 旧测试仅查 QPushButton，无法覆盖换入的原版 IconButton。改为查可见控件并
   真实鼠标点击，保留长文/通知场景及真实接收端数据库断言。

## 不能宣称已迁移的部分

MainWindow、Qt 布局、QListWidget 宿主、文件卡片、设置/共享/传输/投屏等对话框
仍为定制代码。会话行绘制和气泡是注明来源的适配，不是完整 Dialogs/HistoryView。
完整迁移还要替换 Session、HistoryItem、搜索和订阅等数据契约，不只是替换网络层。
