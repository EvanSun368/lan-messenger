# Windows 便携版构建与验收

本目录是构建配置，不是已经编译的 Windows 程序。
当前云环境为 Linux，未连接 Windows、未配置本项目的 Windows CI，未在 Windows 执行此脚本。

## 构建者

使用 Windows 10/11 x64 和官方 Python 3.12 x64，联网后双击根目录 build-windows.bat。
脚本安装依赖，运行所有测试，使用 PyInstaller 目录模式打包，再运行打包后的 EXE 生成演示截图。
只有以上步骤成功，才生成 dist/LanLink-0.4.0-windows-x64-portable.zip 和 SHA256。
任何网络、防病毒或平台依赖问题均应修复后重新构建，不应跳过测试。
构建依赖 PySide6/Qt 许可声明须随包保留；对外分发前由所有者核对适用许可义务。

## 使用者

收到真正的 portable.zip 后，解压整个 LanLink 文件夹，双击 LanLink.exe。
无需另装 Python。不可仅复制 EXE，必须保留 _internal 等所有文件。
未签名开发预览可能触发 Windows 提示，不建议关闭安全软件。
仅在可信局域网使用。若防火墙询问，只允许可信专用网络，不要开放公网。
设置与聊天记录仍存放在用户目录，不是所有数据都存于解压目录。

## 必须区分的验证层次

脚本自动验证：单元测试、打包 EXE 启动、演示 Qt 窗口截图和正常退出。
仍需 Windows 实机手工验证：中文/高 DPI、真实网络发现、两机聊天和传输、断点续传、截图授权、多人投屏。
演示模式不开网络，不代表上述真实功能已验收。
免安装包不注册卸载程序；关闭后删除解压目录即可移除程序，不会自动删除用户聊天记录。
