# 反馈修订验收范围

## 版本必须分开
- 用户确认实际运行的是先前 Windows Python 0.4.0 便携包。
- 用户报告“对方接收共享文件时崩溃”。当前云端测试没有复现，不能将 C++ 更新称为已经修好该旧版本特定崩溃。
- C++/Qt 0.5.1 是新的原生预览；独立数据目录，不自动导入旧聊天/身份。

## 本轮验证重点
- 飞鸽风格窄联系人窗 + 独立会话窗；不改回 QQ 三栏气泡方案。
- 输入区尺寸、发送快捷键、历史搜索、图片查看；次要功能收进菜单。
- 非当前会话的新消息未读状态；激活/阅读后清除；关闭通知不丢未读。
- 分类 Unicode 表情与最近使用；显示取决于系统字体，不是专有动态表情包。
- 共享发布、浏览、中文名下载、撤销；接收异常需保留版本和具体触发步骤，不能用演示截图代替真实网络测试。

## 尚需真实 Windows 验证
托盘与系统通知、焦点/免打扰系统行为、显示缩放与字体、两台实体电脑接收共享文件、断点续传、投屏。
GitHub 构建受账户支付/额度限制，不能将旧 EXE 重新标为当前版本。
